# AI-Based Smart Attendance System

## Overview
An AI-powered Smart Attendance System built using Python and OpenCV. The system detects and recognizes student faces through a webcam and automatically records attendance with date and time.

## Features
- Face Detection
- Face Recognition
- Student Registration
- Image Capture
- Model Training
- Automatic Attendance
- CSV Attendance Report
- Duplicate Attendance Prevention

## Technologies Used
- Python
- OpenCV
- NumPy

## How to Run

1. Install requirements
2. Capture student images
3. Train the model
4. Run attendance_system.py
